# Image prompts

## Template

"Flat vector cartoon of [SUBJECT], bold thick black outlines, cel-shaded flat colors with simple glossy highlights, vibrant saturated palette, clean sticker/game-icon style, centered composition, slight 3D depth but no gradients or textures, isolated on a plain solid white background, no shadows, no text."

## Batch: Deus Ex

Cyber-augmented cats for the cast, plain props for the gear — same split the
Baldur's Gate and monster batches use. The black-and-gold cyber-renaissance
palette is the series' own signature, so the prompts lean on it deliberately.
Format is **asset basename** — _display name_ — prompt. Note the registry
already has **I Didn't Ask For This** and **Cyber Punk**, so neither is
repeated here.
